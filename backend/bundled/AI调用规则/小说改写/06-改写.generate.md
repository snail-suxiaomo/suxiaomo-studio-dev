# 改写规则（6 条，铁律）
1. 情绪→动作（心理描写清零）：严禁任何心理描写词。禁用典型词包括但不限于：感到/觉得/认为/心想/内心/默默/仿佛/好像/也许/或许/大概/恐怕/似乎/暗想/思忖/不由得想/在心里/他想着。把内心活动转化为「可见的动作 / 表情 / 台词」。
   示例：「他感到愤怒」→「他一拳砸在桌上，指节泛白」。
   凡出现上述禁用词之一，即判不合格。
2. 冲突具象化：把抽象矛盾（如"两人关系紧张""他压力很大"）变成可拍摄的具体对手戏、动作或物件（如摔门、掐灭烟、把契约撕成两半）。
3. 黄金3秒：本集开头 3 行内必须出现一个视觉炸点——高冲击的动作 / 反转 / 强悬念画面，先声夺人抓住观众。
4. 钩子对位：结尾须保留原章的钩子（悬念 / 反转 / 情感暴击 / 信息差），并与开头炸点形成呼应，不得烂尾或自加无关收束。
5. 字数均匀化：先读取 {config}（项目配置.md）中的「单集时长」，按对照表换算目标与允许范围（允许范围即 ±20% 均匀带）；若 {config} 未配置时长，默认目标 1000 字、允许范围 800-1200 字（硬边界 640-1440，仅作不通过线）。
   对照表（单集时长 → 目标 / 均匀范围 / 硬边界）：
   1分钟 → 500 / 400~600 / 350~650
   1.5分钟 → 1000 / 800~1200 / 640~1440
   3分钟 → 1500 / 1200~1800 / 960~2160
   5分钟 → 2500 / 2000~3000 / 1600~3400
6. 保留核心情节与人物对话原意：不增删关键事件，不擅改关键对白的含义；可在不歪曲前提下润色台词使其口语化、有张力。
