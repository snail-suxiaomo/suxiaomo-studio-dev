本步为规则解析（非 AI 生成），由 Python 正则切分，规则如下：

【拆分单位】仅识别五类标记（正则：第 + 数字/中文数字 + 单位）：
  章 / 回 / 卷 / 集 / 节
拒绝作为拆分单位：数字、天、日、话、部、篇、幕、季、册 等

【主格式判定】
- 统计各格式在【行首】的命中数，取最多者为「主格式」
- 只按主格式切分；其他单位（回/集/卷）若在正文中出现属于正常行文，不单独成章

【番外识别】
- 行首单独出现的关键词（番外、后记、if线、小剧场、附录、完结感言、完本感言）→ 独立成 extra 章
- 标题式行判定：关键词后跟 空格/：/·/—/数字/汉字数字 或行尾，且整行 ≤40 字
- 命中后独立输出 第N章.md（不计入正文章节数），正文前标「> 所属：番外」

【标题与正文】
- title = 完整标题行（第1章 没什么事，我先挂了），而非仅正则匹配的标记
- content = 正则匹配结束位置之后、下一章节标记之前的所有文本

【文件解码】
- .txt：utf-8 / gbk / gb18030
- .epub：ebooklib + BeautifulSoup 提取 xhtml 正文（不产生重复标题行）

【输出规范】
- 目录：projects/<项目名>/00-拆分/
- 文件：第1章.md / 第2章.md …（按输出顺序连续正整数，番外占一个序号）
- 文件头：# {完整标题行}
- 番外首行：> 所属：番外
- 每章结尾：---
- 编码：UTF-8

【诊断与报告】
- Python 诊断：格式检测 / gap 缺失 / 巨型章 / 番外统计 / 首尾采样
- 迷你章、噪音、序号重复暂不判断
- 用户可手动忽略不认同的诊断异常，或使用 AI 辅助分析
- 00-小说拆分报告.md 只记录拆分时仍存在的有效异常
