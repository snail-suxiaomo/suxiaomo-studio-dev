本功能由 Python 规则自动拆分，无需 AI 生成指令。

拆分流程：
1. 导入小说 → 存入 00-拆分/小说原文/ + Python 诊断（格式/字数/gap/巨型章/番外统计/首尾采样）
2. 用户可主动使用 AI 辅助分析（基于诊断结构）
3. 确认后执行拆分 → 输出 00-拆分/第N章.md（完整标题行）

拆分规则见「格式校验（py_format）」。
