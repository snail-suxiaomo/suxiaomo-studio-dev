## 审核要点
1. 12个字段是否齐全、格式是否为「字段名：内容」？
2. "300字梗概"是否精炼、准确反映情节且不超过300字？
3. "钩子"类型是否在允许范围（悬念/反转/情感/信息差/无）内？
4. 内容是否准确、无遗漏、无多余虚构？
5. "序号"字段只需存在即可，阿拉伯数字（1/2）或中文数字（一/二）均可接受，不要因数字书写格式判 FAIL。

请回复：
- 完全符合 → PASS
- 有问题 → FAIL: <具体问题描述，指明哪个字段/什么错误>

【输出格式强制要求】
- 第一行（整个回复的开头）必须是且仅是判定词 PASS 或 FAIL，不得加任何前缀（直接写 PASS 或 FAIL，不要写"通过/不通过"作为判定词）。
- 仅当某一项确实存在真实违反时，第一行才写 FAIL，并只列出真正未通过的项（已通过的项不要列作问题）。
- 若所有检查项均通过，第一行必须写 PASS，严禁写 FAIL。
