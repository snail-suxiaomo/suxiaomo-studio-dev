## 审核要点
1. 是否每章一行，且都含 章号 / 归属集 / 单集时长 / 节奏 四要素？
2. 是否给出「总集数：K」，且 K 与各章归属集最大值一致（集数对齐）？
3. C 级过渡章若被跳过为独立集，是否标注了「注入目标集」与注入方式（对白/旁白），确保 C 级信息零丢失？
4. 相邻集的悬念 6 型是否未连续重复（信息差 / 威胁突现 / 决定时刻 / 身份反转 / 规则改变 / 情感暴击）？
5. 相邻集的情绪 / 状态衔接是否合理（如高潮后不直接接平淡过场，节奏递进自然）？

请回复：
- 完全符合 → PASS
- 有问题 → FAIL: <具体问题描述，指明哪章/哪集/哪个字段或规则不符>

【输出格式强制要求】
- 第一行（整个回复的开头）必须是且仅是判定词 PASS 或 FAIL，不得加任何前缀（直接写 PASS 或 FAIL，不要写"通过/不通过"作为判定词）。
- 仅当某一项确实存在真实违反时，第一行才写 FAIL，并只列出真正未通过的项（已通过的项不要列作问题）。
- 若所有检查项均通过，第一行必须写 PASS，严禁写 FAIL。
